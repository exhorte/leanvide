# Service API — reserve au Cloud facultatif

Ce repertoire ne contient volontairement aucun backend executable en Phase 01.
Le MVP Fluent fonctionne localement, sans compte ni Cloud; aucun audio ou texte
ne doit quitter la machine sans consentement explicite.

Python 3.14.5 est la version prevue pour un futur service facultatif. Elle ne
doit pas etre installee, configuree ni executee pour construire, tester ou
lancer l'application de bureau de cette phase. Toute activation future exige un
contrat d'API, une decision produit, une revue securite et des preuves de
consentement.
